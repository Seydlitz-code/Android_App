    "progress_percent": info.get("progress_percent", info.get("progress", 0)),

5) (선택) 미세 진행률 함수 추가 후 단계 사이에서 호출:

def _update_progress_numeric(task_id: str, percent: int, msg: str):
    info = _redis_get(task_id)
    if info is None:
        return
    pct = max(0, min(100, int(percent)))
    info["progress"] = pct
    info["progress_percent"] = pct
    info["message"] = msg
    _redis_set(task_id, info)

- process_zip_task 호출 전: _update_progress_numeric(task_id, 12, "ZIP 압축 해제·이미지 준비 중...")
- process_zip_task 호출 후: _update_progress_numeric(task_id, 20, "전처리 완료, GPU 단계로...")
